# Boogying Down Scary Street

A first-person browser bullet-heaven set on Scary Street. Survive the waves, beat the bosses, master the fade.

## Play
Open `index.html` in a modern desktop browser (Chrome, Edge, Firefox). Keyboard + mouse or a controller.

## Tech
Single-file HTML5 game built with three.js (loaded from cdnjs). No build step. Just host `index.html`.
